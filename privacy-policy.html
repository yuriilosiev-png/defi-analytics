1. About This App

DeFi Analytics is a personal portfolio tracker for decentralized finance (DeFi) investors. It is a free web application available at yuriilosiev-png.github.io/defi-analytics/ and as an Android app.

The app helps users monitor their DeFi positions across multiple protocols and blockchains, including Aave, Morpho, Compound v3, Euler v2, Uniswap (v3 and v4), GMX (perpetuals, GM, GLV and GLP), Merkl, and Solana.

2. Data We Collect

DeFi Analytics does not require registration and does not collect names, email addresses, phone numbers, or any other directly identifying information. We have no user accounts. If you enable the optional push alerts, a small amount of pseudonymous technical data is processed on our alert server (section 4).

What you enter into the app

The only input the app uses is your public blockchain wallet address (e.g. 0x... for EVM chains or a base58 address for Solana). This address is:

  • Stored locally on your device using browser localStorage
  • Used to query public blockchain APIs and public RPC nodes (section 3)
  • Sent to our alert server only if you enable push alerts (section 4); otherwise it never reaches any server operated by us
  • Never sold, and never shared with third parties for advertising or profiling
Journal and settings data

Any data you manually enter (journal entries, pool settings, asset allocations) is stored exclusively on your device using browser localStorage. This data never leaves your device.

3. Public Blockchain Data

To display your DeFi positions, the app queries the following public APIs using your wallet address:

  • Ankr API — multichain EVM token balances and Aave positions
  • Helius API — Solana native balance and SPL token balances
  • DefiLlama — DeFi protocol positions across chains
  • Merkl API — accumulated DeFi rewards
  • Morpho GraphQL — Morpho Blue lending positions
  • GMX API and subgraph — GMX perpetual positions and token prices; GM, GLV and GLP balances are read directly from the blockchain
  • Public RPC nodes — direct on-chain reads (Aave, Compound v3, Euler v2, Uniswap v3/v4, GMX) through public endpoints such as publicnode, Ankr, LlamaNodes and the networks' own public RPCs
  • Blockscout — EVM fallback when Ankr is unavailable; lookup of Uniswap v4 position NFTs
  • Binance / CoinGecko / CryptoCompare — asset price feeds

All blockchain data queried is public information — the same data anyone can view on a block explorer by entering your address. These third-party services may log technical data such as your IP address under their own policies; we do not control them.

4. Push Alerts (Optional)

The app can send push notifications (Health Factor drops, asset price levels) even when it is closed. This works only if you switch push on in the Alerts tab and allow notifications in Android. When enabled, the app sends the following to our alert server (a Cloudflare Worker with Cloudflare Workers KV storage):

  • your Firebase Cloud Messaging device token (an anonymous identifier of the app installation on your phone)
  • the public EVM wallet addresses saved in the app
  • your alert settings: thresholds, assets, trigger mode, sound on/off, language
  • technical hints about your open loan positions (e.g. Compound market and Euler sub-account contract addresses) so that the server can check them efficiently

The server uses this data only to check public blockchain and price data every 5 minutes and to send you a notification through Firebase Cloud Messaging (Google). It is not used for analytics, advertising or profiling, and it is not sold or shared with anyone other than the infrastructure providers needed to deliver the notification (Cloudflare, Google/Firebase).

Retention and deletion. The data is kept only while push alerts are on. Switching push off in the app deletes your subscription from the server. A subscription is also deleted automatically when Google reports that the device token is no longer valid (for example after the app is uninstalled) the next time the server tries to deliver a notification to it. You can also ask us to delete it by contacting us (section 11); please include the wallet address you used.

Without push enabled, none of this data is sent.

5. Telegram Integration (Optional)

The app includes an optional Telegram notification feature via the @DefiAnalytics2bot bot. If you choose to use this feature:

  • You provide your Telegram username to connect the bot; the app looks up your Telegram chat ID through the relay server
  • The bot sends alerts to your Telegram account (Health Factor drops, price levels, LP range exits). To deliver them, the alert text and your chat ID pass through the relay server
  • The relay server operates on the Render.com cloud service solely to relay alert messages
  • Your Telegram username is stored locally on your device
  • This feature is entirely optional and can be skipped

6. Cookies and Tracking

DeFi Analytics does not use cookies, does not use analytics tools (Google Analytics, Firebase Analytics, etc.), and does not contain any advertising or third-party tracking scripts. Firebase Cloud Messaging is used only to deliver push notifications you have switched on (section 4).

Data persistence is achieved solely through browser localStorage, which is local to your device and not accessible by any server.

7. Children's Privacy

DeFi Analytics is intended for adults (18+) interested in decentralized finance. The app does not knowingly collect data from or target children under the age of 18.

8. Security

The app stores your settings and journal locally and transmits only public wallet addresses (and, for push alerts, the data in section 4); it never handles private keys, so the security risk is minimal. However, users should be aware:

  • Never enter your private key or seed phrase anywhere in this app — it is not required and should never be shared
  • The app operates in watch-only (read-only) mode — it cannot sign transactions or move your funds
  • Price and position data is sourced from third-party APIs and may occasionally be inaccurate
